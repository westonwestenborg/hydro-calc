# Hydroponics Calculator

A simple, clean calculator for hydroponics nutrient solutions. This tool helps you calculate the right amount of nutrients for different crops in hydroponic systems.

## 🌱 Live Demo

Visit the live application: [Hydroponics Calculator](https://westonwestenborg.github.io/hydro-calc/)

## ✨ Features

- Calculate nutrient requirements for various crops
- Simple, clean UI with no unnecessary elements
- Mobile-friendly responsive design
- Crop-specific emoji indicators
- Quick search functionality
- Default measurements in ml for convenience

## 🔧 Technologies Used

- React
- TypeScript
- Vite
- Custom CSS (no frameworks)
- Zustand for state management

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or newer)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/westonwestenborg/hydro-calc.git

# Navigate to the project directory
cd hydro-calc

# Install dependencies
npm install

# Start the development server
npm run dev
```

## 📦 Deployment

This project is configured for GitHub Pages deployment:

```bash
# Build and deploy to GitHub Pages
npm run deploy
```
